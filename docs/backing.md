# 재즈 연습 반주 엔진

`src/lib/backing.ts`의 `JazzBacking`은 코드 진행을 Web Audio로 합성하는 연습용 반주기다. 원곡 녹음·멜로디·음원 샘플을 재생하지 않는다. 외부 오디오 파일이나 샘플 라이선스가 필요하지 않고 모든 소리를 브라우저에서 만든다.

- 피아노: 사인파 배음 4개와 감쇠 엔벌로프를 이용한 코드 보이싱.
- 베이스: 배음 3개와 짧은 플럭 엔벌로프. 코드 구성음으로 워킹 패턴, 보사에서는 루트·5도 중심 패턴을 만든다.
- 드럼: 절차적 노이즈와 필터를 사용한 라이드·스네어·브러시, 낮은 사인파 킥.
- Swing, Bossa, Ballad, Straight는 서로 다른 컴핑·베이스·드럼 리듬을 사용한다. 실제 연주 녹음을 대체하는 음질을 주장하지 않는다.

`parseJazzChord()`로 코드의 장·단3도, 7도, 디미니시, 텐션, 슬래시 베이스를 해석한다. 사용자 키 이동은 피아노와 베이스 모두에 적용되며 드럼의 주파수는 바뀌지 않는다. 한 마디의 코드 수가 3개처럼 박수의 약수가 아니어도 마디 길이를 균등하게 나누어 정확한 분수 박 위치에서 바뀐다. N.C.는 화성 악기 없이 리듬만 진행한다.

스케줄러는 25 ms마다 오디오 시계를 확인해 약 120 ms 앞까지 예약한다. 템포·키·믹스 변경은 다음 예약부터 적용되고, 패턴·박자·폼 변경은 다음 마디에 반영된다. 미리 예약된 짧은 구간과 이미 울리는 음은 즉시 다시 합성하지 않는다. 배경 탭에서 돌아왔을 때 놓친 음을 몰아서 재생하지 않고 현재 위치에서 다시 이어간다.

`BackingPosition`의 `bar`와 `beat`는 0부터 시작하고 `chorus`는 1부터 시작한다. `chord`는 현재 키로 전조된 문자열이다. `loopStart`와 `loopEnd`는 포함 범위이며 반복이 꺼져 있으면 전체 곡의 끝에서 종료한다. `countIn`은 해당 박자로 먼저 재생하는 마디 수이다. 재생 중지와 종료는 예약된 화면 콜백·음원·오디오 노드를 정리한다. 마스터 컴프레서와 낮은 합성 게인으로 여러 음이 겹치는 피크를 줄인다.

`tests/backing.test.ts`는 실제 악기 음질 대신 재생 계획과 스케줄링을 검증한다. 분수 코드 경계, 코드 종류·텐션·슬래시 베이스, 전조, 박자별 카운트인, 유한 재생, 포함 루프 범위, 코러스 증가, 실시간 템포·키 변경, 탭 복귀, 시작 취소·오디오 오류와 정지를 가상 오디오 시계에서 확인한다.

오디오 예약 방식: [MDN Web Audio API의 시퀀서와 스케줄링](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Advanced_techniques).
