# JUNO Guitar Studio

기타·베이스 튜너, 코드·스케일 지판, 재즈 악보와 반주, 메트로놈을 모은 한국어 웹 연습실입니다. 마이크 또는 오디오 인터페이스로 튜닝하고, Google 계정에 연습 설정을 저장할 수 있습니다.

- **웹앱:** [guitar-juno.web.app](https://guitar-juno.web.app)
- **코드:** [YooJuno/guitar-studio](https://github.com/YooJuno/guitar-studio)
- **기술:** React · TypeScript · Vite · Web Audio · Firebase Authentication / Firestore / Hosting

## 기능

### 튜너

입력은 **정지 버튼을 누를 때까지 유지**됩니다. 다른 도구로 이동하면 화면 분석만 쉬며, 돌아오면 같은 입력으로 다시 측정합니다. 장치·채널을 변경하면 자동으로 재연결합니다. 다른 탭에서는 상단 튜너 아이콘으로 정지할 수 있습니다.

- 기타 6·7·8현, 베이스 4·5·6현 프리셋 **33개**
- Standard, 다운 튜닝, Drop D/C/B/A, DADGAD, Open D/G/C 등
- 현별 사용자 튜닝, A4 기준 피치, 기준음 재생, 즐겨찾기
- 한 현씩 측정하는 단음 모드와 여러 개방현을 확인하는 **동시 모드**
- 상단 설정에서 입력 장치·L/R 채널·A4·현별 목표음 변경, 튜너 화면에서 입력 레벨과 클리핑 확인
- 작아지는 현 소리를 주기성과 신뢰도로 추적하고, 짧은 끊김에는 마지막 측정값을 구분해 표시

동시 모드는 PolyTune의 여러 현을 한 번에 확인하는 사용 경험을 참고한 독립 구현입니다. 상용 페달의 알고리즘·정확도를 재현했다고 주장하지 않습니다. 배음이 겹치거나 신호가 약하면 현을 놓치거나 잘못 감지할 수 있으므로 마지막은 한 현씩 확인하세요. 미검출 현을 임의의 측정값으로 채우지 않으며, 잠시 유지하는 과거 값도 현재의 녹색 정음 판정으로 표시하지 않습니다.

### 코드와 스케일

- 12개 근음, 코드 품질 **18종**, 스케일 **20종**
- 7개 기본 모드, 펜타토닉, 블루스, 하모닉·멜로딕 마이너, 얼터드 등
- 현재 튜닝에 맞춘 지판·구성음·인터벌·보이싱과 소리 재생
- 운지 넘기기와 지판의 프렛 범위 선택, 지판에서 개별 음 듣기
- 코드 화면의 스케일 버튼 또는 재즈 차트의 코드 이름을 눌러 추천 음계·코드톤·지판 확인

재즈 차트에서는 전조된 코드와 곡의 키, 이어지는 화음을 반영해 스케일 후보의 순서를 정합니다. 슬래시 베이스와 기호에 적힌 텐션을 포함하는 후보만 표시합니다. 스케일을 고르면 코드톤을 어떻게 포함하는지와 곡의 키, 다음 코드 또는 스케일 고유 음정에 따른 추천 이유를 확인할 수 있습니다. 곡의 멜로디에 따라 다른 선택도 가능합니다. [이론 출처](docs/references.md#harmony-and-scales)

보이싱은 구성음과 프렛 범위를 기준으로 계산한 후보입니다. 실제 운지는 손 크기·악기·바레 사용에 따라 달라집니다.

### 재즈 악보와 반주

- 스탠다드·전통곡·오리지널 연습곡 **12곡**, 내장 오선 악보 **4곡**
- 재생·템포·키는 한 줄에 표시하고, 반주 설정의 재생·믹서 탭과 악보는 따로 열 수 있음
- 코드 차트·오선 악보·내 PDF 전환, 키 이동, 정식 악보 출처 링크
- 코드 차트를 따르는 **녹음 샘플 기반 피아노·더블베이스·어쿠스틱 드럼 반주**
- Swing / Bossa / Ballad / Straight, 템포·악기별 믹서, 차트와 반주에 함께 적용하는 12개 키 선택
- 카운트인, 현재 마디 하이라이트, 곡 끝에서 자동 정지
- **내 음원:** 기기에 있는 음원의 속도·키 조절과 탐색

반주는 Splendid Steinway 피아노, D. Smolken 피치카토 더블베이스, Guigui 어쿠스틱 드럼의 녹음을 악기별로 재생합니다. 40개 샘플을 M4A·OGG 두 형식으로 직접 제공하며 전체 약 **5.29MB**, 첫 재생의 기본 M4A 약 **2.8MB**를 지연 로드하고 재사용합니다. 출처·공개 도메인/CC0 조건은 [샘플 고지](public/samples/jazz-v1/NOTICE.txt)에 있습니다. 샘플 준비가 실패하면 오류를 알리며 합성음으로 대체하지 않습니다.

Safari의 Audio Session API를 지원하는 기기에서는 반주를 `playback`으로 선언합니다. 튜너 입력이 켜져 있으면 `play-and-record`를 우선해 마이크를 유지합니다. 샘플 로딩 후 오디오 상태를 다시 확인하고, 시작 대기는 4초로 제한합니다. 재생 중 출력이 중단되면 재생 버튼으로 다시 시작할 수 있으며, 작은 출력 막대는 실제 믹스 신호를 표시합니다.

이 반주는 원곡 녹음이나 원곡 멜로디 재생이 아닙니다. 상업용 곡은 연습용 코드 진행과 정식 출판 악보 링크를 제공하며, Real Book 전체 PDF나 저작권 멜로디 악보를 무단 복제하지 않습니다.

내 음원은 브라우저가 지원하는 MP3·WAV·M4A 등의 파일을 **150MB까지** 열 수 있습니다. 속도는 **0.5–1.5배**, 키는 SoundTouch AudioWorklet으로 조절합니다. 원음 키를 지정하면 차트 키와의 차이를 반영합니다. AudioWorklet 미지원·초기화 실패 시 속도 조절만 제공하고 키 변경은 비활성화합니다. 파일은 업로드되지 않으며 새로고침 후 다시 선택해야 합니다. 큰 전조·느린 재생에는 음색 변형과 지연이 생길 수 있습니다.

### 메트로놈

- 20–300 BPM, 입력·슬라이더·± 버튼·탭 템포
- 박별 강세·일반·쉼, 박자·세분박·2:1 스윙
- Wood / Digital 클릭, 볼륨, 카운트인
- 리듬·타이머·프리셋 설정 탭, 마디별 템포 증가와 자동 정지

BPM은 선택한 박 단위 기준입니다. 예를 들어 6/8의 한 박은 8분음표 하나입니다. Web Audio 시계로 예약하며, 중단된 탭에서 돌아올 때 놓친 클릭을 몰아서 재생하지 않습니다.

### Google 로그인과 저장

- Google 로그인, 우상단 계정 메뉴에서 로그아웃, 계정별 Firestore 설정 저장
- 비로그인 상태의 기기 내 설정과 계정별 로컬 캐시
- 본인 UID의 설정만 읽고 쓰도록 제한하는 서버 보안 규칙

`guitar-juno`의 Google 제공업체와 기본 배포 도메인은 설정되어 있습니다. Google 로그인 URL 생성 API도 확인했습니다. 다른 Firebase 프로젝트에 복제할 때는 [설정 문서](docs/firebase-setup.md)를 참고하세요.

## 로컬 실행

Node.js **24 LTS**와 npm을 권장합니다.

```sh
git clone https://github.com/YooJuno/guitar-studio.git
cd guitar-studio
npm ci
npm run dev
```

터미널에 표시된 주소를 엽니다. 마이크는 HTTPS 또는 `localhost`에서 사용할 수 있습니다. 휴대폰에서 단순 HTTP LAN 주소로 접속하면 마이크가 차단될 수 있으므로 배포된 HTTPS 주소를 사용하세요.

```sh
npm test
npm run build
npm run preview
```

테스트는 신호 분석·음악 이론·메트로놈·재즈 반주·로컬 음원 수명을 검사합니다. 빌드는 TypeScript 검사 후 `dist/`를 생성합니다. GitHub Actions는 PR과 `main` 푸시에서 설치·테스트·빌드를 실행합니다.

## 실제 악기로 튜닝하기

1. 악기·튜닝을 고르고 입력을 시작한 뒤 마이크 권한을 허용합니다.
2. 인터페이스를 쓰면 연결한 장치와 입력 채널을 선택합니다.
3. 다른 현을 뮤트하고 한 현씩 울립니다. 동시 모드에서는 선택한 튜닝의 개방현을 함께 울립니다.
4. 입력이 작으면 게인을 올리고 클리핑 표시가 나면 낮춥니다. 저음은 안정될 때까지 잠시 기다립니다.
5. 기준음·반주·메트로놈이 입력에 섞이지 않도록 헤드폰을 사용하거나 재생을 멈춥니다.

브라우저·휴대폰의 음성 처리와 마이크 저음 응답은 기기마다 다릅니다. DI/Hi-Z 입력은 주변 소음 영향을 줄이는 데 유리합니다. 분석 창과 감쇠음 추적의 동작은 [튜너 설계](docs/audio-research.md)에 정리했습니다.

## 검증 범위

현재 자동 테스트는 **80개**입니다. 감쇠하는 기타 합성 신호, 조용한 노이즈, 낮은 B0, 동시 현, 코드·전조·코드별 스케일 후보, 가상 오디오 시계의 예약·반복·취소·중단 감지, 파일·노드 해제, 실제 샘플 파일의 해시·매핑·코덱 대체·취소·재사용을 포함합니다.

브라우저에서는 폭 **390px** 화면에서 반주 재생 경로·템포·키·마디 하이라이트를 확인했습니다. 모바일 세션 수정 후 브라우저의 마스터 출력 분석기에서 약 −20~−22dB 신호를 확인했습니다. 이는 실제 휴대폰 스피커 청취를 대신하지 않습니다. 생성한 WAV를 열어 **0.75배 / −1반음 재생**과 일시 정지도 확인했으며 이 점검 중 콘솔 경고·오류는 없었습니다. 390px 확인은 브라우저 화면 폭을 맞춘 점검입니다. 실제 샘플 렌더러의 16마디 WAV는 기본 믹스 피크 **0.2795**, RMS **0.0240**이었고 최대 레벨·전조·템포 스트레스 렌더의 피크도 **0.758 이하**로 디지털 클리핑이 없었습니다. 이 수치 검증에 청취 평가는 포함하지 않습니다. [상세 검증](docs/backing.md#검증과-출처)

실제 휴대폰 마이크의 기타 감쇠음, 실제 악기·인터페이스의 튜닝 정확도, 모바일 코덱과 출력 지연, 사용자 계정의 Google 로그인 전체 흐름은 별도 실기기 확인이 남아 있습니다. 합성 신호와 가상 시계 테스트를 실제 장치 성능 인증으로 해석하지 않습니다.

## Firebase 배포

프로젝트 배포 권한이 있는 계정으로 CLI에 로그인합니다.

```sh
npx firebase-tools login
npm ci
npm test
npm run build
npx firebase-tools deploy --only hosting,firestore:rules --project guitar-juno
```

프로젝트 연결은 `.firebaserc`, Hosting·보안 헤더·SPA 라우팅은 `firebase.json`, 데이터 권한은 `firestore.rules`에서 관리합니다. CI는 인증 없는 자동 배포를 수행하지 않습니다. 배포 자동화가 필요하면 별도로 단기 인증을 구성하세요.

## 개인정보와 오픈소스

- 마이크 파형과 선택한 음원 파일은 브라우저에서 처리하며 서버로 업로드·녹음 저장하지 않습니다.
- Google 비밀번호는 앱이 받지 않습니다. 인증과 계정 설정 저장에는 Google/Firebase 연결이 필요합니다.
- 사용자 설정은 `users/{uid}/preferences/main`에 저장하며 다른 계정의 설정과 컬렉션 목록은 읽지 못하도록 제한합니다.
- Firebase 웹 API 키는 공개 앱 구성입니다. 관리자 서비스 계정 비밀키와는 다르며 데이터 권한은 인증과 보안 규칙으로 제한합니다.
- SoundTouchJS **2.1.1 / MPL-2.0**의 고지·라이선스 전문·릴리스 소스 안내를 배포물에 포함합니다. [고지](public/third-party-notices.txt) · [라이선스](public/licenses/MPL-2.0.txt)
