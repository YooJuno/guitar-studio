# JUNO Guitar Studio

기타와 베이스의 튜닝부터 코드, 모드 스케일, 재즈 악보와 리듬 연습까지 한곳에서 사용하는 한국어 웹 연습실입니다. 브라우저의 마이크 또는 오디오 인터페이스 입력을 분석하며, Google 계정으로 연습 설정을 저장할 수 있습니다.

- 배포 대상: [guitar-juno.web.app](https://guitar-juno.web.app)
- 소스: [YooJuno/guitar-studio](https://github.com/YooJuno/guitar-studio)
- 기술: React · TypeScript · Vite · Web Audio API · Firebase Authentication · Cloud Firestore · Firebase Hosting

## 기능

### 튜너

- 기타 6·7·8현, 베이스 4·5·6현의 튜닝 프리셋 33개
- Standard, 반음·온음 다운, Drop D/C/B/A, DADGAD, Open D/G/C 등
- 현별 사용자 튜닝과 기준음 A4 조절
- **단음 모드**: 한 음의 음높이·주파수·센트 편차 확인
- **폴리 모드(실험)**: 선택한 튜닝의 여러 개방현을 동시에 분석하여 각 현의 편차 확인
- 입력 장치와 채널 선택, 입력 레벨 표시, 기준음 재생

폴리 모드는 TC Electronic PolyTune의 여러 현을 한 번에 확인하는 사용 경험을 참고했습니다. 상용 페달의 알고리즘 또는 정밀도를 재현한 제품은 아닙니다. 선택한 튜닝 주변의 배음을 분석하므로 줄이 많이 틀어졌거나, 옥타브 관계의 현이 겹치거나, 기본음이 약하면 미검출·오검출할 수 있습니다. **대략적인 동시 확인 후 한 줄씩 마무리 튜닝**하는 사용을 권합니다. 검출되지 않은 현은 임의의 음으로 채우지 않습니다.

### 코드와 스케일

- 12개 근음과 메이저·마이너·7th·9th·sus·dim·aug 등 코드 품질 18종의 구성음
- 현재 튜닝을 반영한 코드 보이싱과 지판 확인
- 7개 기본 모드, 펜타토닉, 블루스, 하모닉·멜로딕 마이너, 얼터드 등 스케일 16종
- 음 이름·구성음·인터벌 확인과 소리 재생

생성된 보이싱은 음높이와 프렛 범위를 기준으로 계산합니다. 실제 운지는 손 크기·악기·바레 사용에 따라 어려울 수 있으므로 자신에게 편한 포지션을 선택하세요.

### 재즈 연습실

- 스탠다드·전통곡·연습곡을 합한 레퍼토리 12곡과 작곡가·키·형식·스타일 정보
- 권리가 확인된 자료 및 정식 악보 출처 링크
- 앱에 포함된 연습용 코드 진행과 내장 오선 악보 4곡으로 연습
- 보유한 PDF 악보를 브라우저에서 열기

곡 정보, 연습용 진행, 정식 출판 악보는 구분합니다. 상업용 Real Book 전체 PDF나 저작권이 있는 멜로디 악보를 무단 복제하여 제공하지 않습니다. 곡별 자료의 성격과 출처를 확인하세요.

### 메트로놈

- 20–300 BPM, 숫자 입력·슬라이더·± 버튼·탭 템포
- 박별 강세·일반·쉼 설정, 여러 박자와 세분박
- 8분음표 스윙, Wood/Digital 클릭 사운드, 볼륨
- 카운트인, 마디 단위 템포 증가, 자동 정지 타이머
- 자주 쓰는 리듬 프리셋 저장

메트로놈은 Web Audio 시계에 소리를 미리 예약합니다. 운영체제 절전·탭 중단·장치 지연은 영향을 줄 수 있습니다. BPM은 화면의 한 박 기준이며, 6/8에서는 8분음표 한 개가 한 박입니다.

### Google 계정과 저장

- Firebase Google 로그인·로그아웃과 로그인 상태 유지
- 로그인 계정의 설정을 Firestore에 저장
- 비로그인 시 기기 내 설정 사용
- 서버 보안 규칙으로 다른 계정의 설정 접근 차단

Firebase 프로젝트의 Google 제공업체는 활성화되어 있으며 기본 배포 도메인도 승인되어 있습니다. 별도 Console 초기 설정이나 결제 계정 연결 없이 배포 사이트에서 Google 로그인을 사용할 수 있습니다. 실제 계정 로그인 화면과 동작은 사용하는 브라우저에서 확인하세요. [Firebase 설정 문서](docs/firebase-setup.md)에 구성과 오류 해결 절차를 정리했습니다.

## 시작하기

Node.js **24 LTS**와 npm을 권장합니다.

```sh
git clone https://github.com/YooJuno/guitar-studio.git
cd guitar-studio
npm ci
npm run dev
```

터미널에 표시된 로컬 주소로 접속합니다. 마이크 입력은 HTTPS 또는 `localhost`에서 사용할 수 있습니다. 같은 네트워크의 다른 기기에서 단순 HTTP LAN 주소로 접속하면 브라우저가 마이크를 허용하지 않을 수 있습니다.

```sh
npm test
npm run build
npm run preview
```

`npm test`는 음높이 검출·음악 이론·메트로놈의 자동 테스트를 실행합니다. `npm run build`는 TypeScript 검사와 프로덕션 빌드를 실행합니다. 결과물은 `dist/`입니다.

## 실제 악기로 사용하기

1. 튜너에서 악기와 튜닝을 선택하고 입력을 시작합니다.
2. 브라우저의 마이크 권한을 허용합니다. 오디오 인터페이스가 있다면 해당 장치와 입력 채널을 선택합니다.
3. 단음 모드에서는 다른 현을 뮤트하고 한 줄씩 울립니다. 폴리 모드에서는 선택한 튜닝의 개방현을 함께 울립니다.
4. 저음은 안정될 때까지 잠깐 기다립니다. 입력이 작으면 게인을 올리고, 클리핑이 생기면 낮춥니다.
5. 기준음·메트로놈 소리가 입력으로 들어가면 검출에 영향을 줄 수 있습니다. 헤드폰을 사용하거나 기준음 재생을 멈춘 후 측정합니다.

브라우저가 음성용 자동 게인·노이즈 억제를 무시할 수 있습니다. DI/Hi-Z 입력은 주변 소음 영향을 줄이는 데 유리합니다. 낮은 B0를 포함한 긴 분석 창 때문에 폴리 표시는 즉시 반응하지 않을 수 있습니다. [알고리즘과 한계](docs/audio-research.md)에 분석 범위와 지연을 정리했습니다.

## Firebase 배포

배포하려면 Firebase 프로젝트에 권한이 있는 Google 계정으로 CLI에 로그인해야 합니다.

```sh
npx firebase-tools login
npm ci
npm test
npm run build
npx firebase-tools deploy --only hosting,firestore:rules --project guitar-juno
```

프로젝트 연결은 `.firebaserc`, Hosting·보안 헤더·SPA 라우팅은 `firebase.json`, 사용자 데이터 권한은 `firestore.rules`에서 관리합니다. 기존 프로젝트의 규칙을 배포할 때는 전체 규칙 파일을 먼저 검토하세요.

GitHub Actions는 PR과 `main` 푸시에서 설치·테스트·빌드를 실행합니다. 배포 인증이 없는 상태에서 자동 배포를 가장하지 않도록 CI와 배포를 분리했습니다. 자동 배포가 필요하면 별도로 Workload Identity Federation 같은 단기 인증을 설정하세요.

## 개인정보와 보안

- 마이크 소리는 브라우저 메모리에서 분석하며 서버에 전송·녹음 저장하지 않습니다.
- Google 로그인 정보는 Firebase Authentication이 처리합니다. 앱이 Google 비밀번호를 받지 않습니다.
- 사용자 설정은 본인 UID 아래에 저장합니다. 공개 사용자 목록이나 다른 사용자의 설정을 읽는 기능은 없습니다.
- Firebase 웹 `apiKey`, `appId`는 공개 클라이언트 구성입니다. 관리자 권한을 주는 서비스 계정 비밀키와는 다릅니다. 실제 데이터 권한은 보안 규칙과 인증으로 제한합니다.
- 로그인과 설정 저장에는 Google/Firebase로의 네트워크 연결이 필요합니다. 외부 악보 링크는 해당 제공업체 사이트에서 열립니다.

## 구성

```text
src/
  App.tsx                  앱 화면과 연습 설정
  MetronomeView.tsx         메트로놈 조작 화면
  data/                    튜닝 프리셋·스탠다드 자료
  lib/
    audio.ts               장치·채널·마이크 수명 관리
    pitch.ts               YIN 단음·튜닝 기반 폴리 분석
    theory.ts              음·코드·스케일·보이싱 계산
    metronome.ts           Web Audio 메트로놈 스케줄러
    synth.ts               기준음·연습음 생성
    firebase.ts            Google 로그인·계정 설정 저장
tests/                     신호·이론·스케줄링 테스트
docs/                      설계·출처·Firebase 설정
```
